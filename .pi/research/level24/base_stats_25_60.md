# Vanilla base stats, levels 25-60 (rows the F# arrays are missing)

Pure data extraction. No balance commentary, no interpolation, no rounding: every tuple below is a
verbatim row of the source array, copied in source order. Levels 41-60 are included because the source
goes to 60 and the same clamp bug affects them.

Rows in each section are **levels 25, 26, ... 60 in order** — the first tuple is level 25 (source index 24),
the 36th tuple is level 60 (source index 59). The tuples are indented with the 7 spaces the repo uses for
continuation rows, so each block pastes straight in after the current last row of that array. Do not
re-index: prepending a row or dropping the first one shifts all 36 levels.

## Corners worth knowing before the fix

1. **The task brief says "six" 40-row arrays, but there are five.** Only `humanWarriorBase`,
   `humanPriestBase`, `nightElfRogueBase`, `gnomeMageBase` and `nightElfDruidBase` hold 40 rows.
   The remaining fourteen hold exactly 24. So 14 arrays need rows 25-60 appended and 5 already have
   rows 25-40 and only need 41-60.
2. **The clamp is real and is a one-liner.** `dress` is declared at `Content.fs:1744`; the indexing is
   `src/WowRoguelike.Core/Content.fs:1746`:
   `sheet.Base.[max 0 (min (sheet.Base.Length - 1) (level - 1))]` — with a 24-row array every level >= 24
   returns the level-24 row. Note the clamp is by *array length*, so appending rows 25-40 to a 24-row array
   silently moves the clamp to level 40; rows 41-60 must be added in the same pass or the bug just moves
   from level 24 to level 40.
3. **Source quirk, not a transcription error:** `HUMAN_WARRIOR` has two identical adjacent rows, levels 18
   and 19, both `BaseStats::new(44, 33, 41, 22, 26, 168, 0)`. The F# array reproduces that duplicate
   (`Content.fs:1073` and `Content.fs:1074`), which is correct. No other needed array has adjacent
   duplicate rows.
4. **Health/mana columns are class constants**, not totals: `health` and `mana` repeat for a whole class
   across races at a given level and exclude the Stamina/Intellect bonus. Do not add the attribute bonus
   when filling these tuples.
