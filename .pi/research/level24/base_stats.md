# Vanilla 1.12 base character stats @ level 24

Pure data extraction. No balance commentary. Every number below is a verbatim row from a source file, with
its file/line cited. Anything computed rather than quoted is explicitly marked **DERIVED**.

**Primary source (all stat rows):** `wow_world_base` crate, `extended/vanilla/base_stats.rs`
— <https://docs.rs/wow_world_base/latest/src/wow_world_base/extended/vanilla/base_stats.rs.html>

Row semantics: `BaseStats::new(strength, agility, stamina, intellect, spirit, health, mana)` — field order
taken from the struct definition at
<https://docs.rs/wow_world_base/latest/src/wow_world_base/extended/top_level/stats.rs.html> (L24–L53).
`health` and `mana` are the class base constants only (before Stamina / Intellect are added) — see
"How the level-24 columns are known to be 'base' values" below.

## How level 24 was located (indexing proof — decision-critical)

Three independent checks, all from the primary source:

1. `base_stats.rs` declares one `const <RACE>_<CLASS>: &[BaseStats]` per race/class; each array holds exactly
   60 entries and `MAX_LEVEL: u8 = 60` (`extended/vanilla/exp.rs` L3). First entry = level 1.
2. The parallel generated table in `exp.rs` (same `AUTOGENERATED_START` machinery, same macro family) spells the
   indexing out in comments: `400, // Required to ding from level 1` is array element 0 (L10–L11), and
   `31700, // Required to ding from level 24` is element 23 (L34). So **level 24 = array index 23**.
   **Derived from source structure, high confidence.**
3. Level-1 anchor against an independent description of the game: the Human Warrior row's first element is
   `(23, 20, 22, 20, 21, 20, 0)` and a vanilla reference states, for a level-1 warrior, "The warrior has 60
   health, and 22 Stamina, this grants the warrior 40 health bonus to his already existing **20 base health**"
   (<https://vanilla-wow-archive.fandom.com/wiki/Agility>, §Stamina). That gives base health 20, stamina 22 —
   matching the first element and its `health` column exactly. **Direct evidence + source interpretation, high
   confidence.**

So: level 24 = 24th row of each array. All rows below are quoted from that position.

# Formulas (each with its source)

## 1. HP from Stamina — first-20-Stamina quirk

Verbatim from `wow_world_base`, `extended/top_level/stats.rs` L1–L10
(<https://docs.rs/wow_world_base/latest/src/wow_world_base/extended/top_level/stats.rs.html>):

```rust
pub const fn health_bonus_from_stamina(stamina: u8) -> u16 {
    let base_stamina = if stamina < 20 { stamina as u16 } else { 20 };
    let additional_stamina = stamina as u16 - base_stamina;
    base_stamina + (additional_stamina * 10)
}
pub const fn calculate_health(base_health: u16, stamina: u8) -> u16 {
    base_health + health_bonus_from_stamina(stamina)
}
```

i.e. **HP = base_health + min(Sta,20)·1 + max(Sta−20,0)·10**. Direct evidence (source code).
Corroborated independently: "Each point of Stamina gives you an additional 10 HP. The first 20 points of
Stamina grants only 1 health point… The warrior has 60 health, and 22 Stamina, this grants the warrior 40
health bonus to his already existing 20 base health" — <https://vanilla-wow-archive.fandom.com/wiki/Agility> §Stamina.

**DERIVED example (level 24 Human Warrior):** Sta 49 → 20·1 + 29·10 = 310; 253 + 310 = **563 HP**.

## 2. Mana from Intellect — the 20 + 15·(Int−20) rule

Verbatim, same file L12–L21:

```rust
pub const fn mana_bonus_from_intellect(intellect: u8) -> u16 {
    let base_intellect = if intellect < 20 { intellect as u16 } else { 20 };
    let additional_intellect = intellect as u16 - base_intellect;
    base_intellect + (additional_intellect * 15)
}
pub const fn calculate_mana(base_mana: u16, intellect: u8) -> u16 {
    base_mana + mana_bonus_from_intellect(intellect)
}
```

i.e. **Mana = base_mana + min(Int,20)·1 + max(Int−20,0)·15**, which for Int ≥ 20 is the familiar
`20 + 15·(Int−20)` on top of the class base mana. Direct evidence (source code).
Corroborated: "Each point of intellect gives you 15 Mana points" —
<https://vanilla-wow-archive.fandom.com/wiki/Agility> §Intellect (that page states the >20 rate only).

**DERIVED example (level 24 Gnome Mage):** Int 60 → 20 + 40·15 = 620; 523 + 620 = **1143 mana**.

## 3. Armour from Agility — 2 per point

"Increases your armor by 2 per point." and, in the same page's Blizzard-developer quotation: "Increases Armor
Class by 2 for every point of AGI." — <https://vanilla-wow-archive.fandom.com/wiki/Agility> §Agility.
Direct evidence (wiki, quoting Blizzard). Note the source gives no separate flat "base armour" term for a naked
character, so **DERIVED: naked armour = 2 × Agility** (Human Warrior @24 = 76, NE Rogue = 120, Gnome Mage = 56,
Human Priest = 52, NE Druid = 74).

## 4. Vanilla armour damage-reduction formula

"For enemies from level 1 to 59, the reduction to physical damage, as a percentage, is given by the following
formula: `%Reduction = (Armor / ([85 * Enemy_Level] + Armor + 400)) * 100`" — verbatim from
<https://wowwiki-archive.fandom.com/wiki/Damage_reduction>. Same page, generalised form: "Reduction = Armor /
(Armor + X) … If the enemy is lower than level 60, X = 85 * Enemy_Level + 400. If the enemy is level 60 or
higher, X = 467.5 * Enemy_Level − 22167.5". Maximum reduction capped at 75%. Direct evidence.

So the constant in `A/(A + 400 + 85·attackerLevel)` is **400 + 85·attackerLevel** for attacker level ≤ 59 —
which is what you asked. **DERIVED, level-24 attacker:** DR = A/(A + 2440). E.g. a naked level-24 Human Warrior
(76 armour) → 76/2516 ≈ **3.0 %** physical DR against a level-24 attacker.

## 5. Class crit-per-agility at level 24 — **UNVERIFIED**

No level-24 table found in any source fetched. The only sourced figures are **level 60**: "For most level 60
character classes, approximately 20 points of AGI will increase your critical hit chance by approximately 1%.
Rogues require 29 AGI for an additional 1% critical hit chance, and Hunters require 53 AGI" —
<https://vanilla-wow-archive.fandom.com/wiki/Agility> §Agility (Blizzard developer quotation). Those are
level-60 values and must **not** be reused at 24 — the conversion is level-dependent (the client `gtChanceToMeleeCrit`
table is per class *and* per level). I did not obtain that table, so:
**crit per agility at level 24 = UNVERIFIED for all five classes.**

# Contradictions

1. **Search-engine summary vs. the primary source (resolved).** An AI answer to the query
   "wow_world_base BaseStats vanilla level 24" asserted the level-24 Human Warrior row is
   `BaseStats::new(37, 29, 35, 21, 25, 118, 0)`. That row is `HUMAN_WARRIOR` L24 = **level 13**, not 24. It is
   also internally inconsistent with what the same answer said about indexing. Reading the source directly gives
   `(52, 38, 49, 23, 29, 253, 0)` at index 23. The primary source wins; **treat the search summary as wrong.**
2. **Level-1 Spirit for Human Warrior: 21 vs 20.** The crate's first `HUMAN_WARRIOR` entry is
   `(23, 20, 22, 20, 21, …)` (Spirit 21); a search-summary paraphrase of
   <https://vanilla-wow-archive.fandom.com/wiki/Warrior_races> reported Spirit 20 ("your list has Spirit 1 too
   high"). Str/Agi/Sta/Int all agree and the base-health anchor agrees, so this does not move the level-24 rows —
   but I did not fetch that page directly, so the discrepancy is **unresolved** (could be a wiki table that lists
   5 attributes vs. one that adds a racial extra, or a bad paraphrase).
3. **Source-data quirks inside the table (not contradictions of my extraction).** The vanilla data itself is not
   monotonic: `HUMAN_WARRIOR` level 10 has base health 101 but level 11 has 100 (L21–L22), and levels 19 and 20
   are byte-identical `(44, 33, 41, 22, 26, 168)` (L30–L31). `NIGHT_ELF_DRUID` level 1 has base mana **17** (L1252)
   where level 2 has 57. These are characteristic of the raw vanilla `player_classlevelstats` data, and none of
   them touch level 24.

  for the Str/Agi/Sta/Int/Spi columns. CMaNGOS `player_levelstats` / `player_classlevelstats` (the natural
  cross-check, e.g. <https://schemaspy.sourceforge.net/unifieddb/mangos/tables/player_classlevelstats.html>) was
  located but the actual 1.12 row data was not retrieved — I did not fetch the multi-MB `mangos.sql` dumps.
  Verification therefore rests on (a) the level-1 anchor against the wiki, (b) the 60-entry/`MAX_LEVEL=60`
  structure and the exp table's own level comments, and (c) cross-race consistency of the health/mana columns.
- **1.12 vs 1.15 (Classic Era) equivalence is UNVERIFIED.** The crate's module is `extended::vanilla`
  (1.12-era client tables). I found no source stating that Classic Era 1.15 ships identical base-stat tables.
  **Researcher inference (medium confidence):** they almost certainly match, since 1.15 reuses the 1.12 data and
  base stats were not retuned — but no source in this run confirms it.
- **Crit-per-agility at level 24:** UNVERIFIED (see formula 5). Also no source found for the vanilla
  `gtChanceToMeleeCrit` level-24 multipliers.
- **Base health/mana constants for Paladin / Hunter / Shaman / Warlock at 24:** not extracted (out of scope) but
  present in the same file if needed.
- No value in this report is an estimate. `UNVERIFIED` is used wherever the source was silent.
