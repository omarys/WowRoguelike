# Wowroguelike-core Specification

> Generated by openlore v1.2.0 on 2026-11-13 21:19

## Purpose

Parses combat log events from the simulation world state to aggregate per-ability and per-caster
damage and healing attribution totals.

## Requirements

> `src/WowRoguelike.Core/Attribution.fs`

### Requirement: Entries

The system SHALL parse combat log lines from the world state into a chronological list of attributable combat entries, classifying auto-attacks, hits, and heals while discarding non-attributable lines.

#### Scenario: ParseSwingsAndAbilityHitsChronologically
- **GIVEN** A world with a reverse-chronological combat log containing swings, ability hits, and heals
- **WHEN** entries is called with the world state
- **THEN** Returns an ordered list of entries sorted oldest first with caster, ability name, and effect amounts

#### Scenario: IgnoreNonAttributableLogEntries
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A world combat log containing lines that do not match swing, hit, or heal markers
- **WHEN** entries is called with the world state
- **THEN** Discards unparseable lines and returns only successfully matched entries

### Requirement: ByAbility

The system SHALL aggregate total damage and healing amounts grouped by caster and ability pairs.

#### Scenario: AggregateTotalsByCasterAndAbility
- **GIVEN** A world with multiple attributable damage and healing events across different abilities
- **WHEN** byAbility is called with the world state
- **THEN** Returns a map keyed by caster and ability name containing running totals for damage and healing

### Requirement: ByCaster

The system SHALL aggregate overall damage and healing totals rolled up per caster across all abilities.

#### Scenario: RollUpTotalsByCaster
- **GIVEN** A world with combat log entries for multiple entities
- **WHEN** byCaster is called with the world state
- **THEN** Returns a map keyed by caster name summing all damage and healing attributed to each entity
