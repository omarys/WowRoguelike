# Tools Specification

> Generated by openlore v1.2.0 on 2026-11-13 21:19

## Purpose

Extracts, processes, and normalizes dungeon floor plans from image maps into connected tile grids
for the Scarlet Monastery dungeon wings.

## Requirements

> `tools/extract_sm_maps.py`

### Requirement: LoadMapImage

The system SHALL the extractor shall load and rasterize a dungeon map image from disk at specified dimensions using an external process.

#### Scenario: LoadExistingMapImage
- **GIVEN** A valid image path and target width and height dimensions
- **WHEN** load is invoked
- **THEN** Raw pixel data corresponding to the requested dimensions is returned

### Requirement: ClassifyPixel

The system SHALL the extractor shall classify an rgb color tuple into a grid tile character based on the designated extraction mode.

#### Scenario: ClassifyFloorOrWallTile
- **GIVEN** An RGB pixel color and an active extraction mode
- **WHEN** classify is evaluated
- **THEN** A representative tile character such as floor or wall is returned

### Requirement: IdentifyComponents

The system SHALL the extractor shall identify contiguous connected components of matching floor or wall tiles in the grid.

#### Scenario: IdentifyConnectedFloorRegions
- **GIVEN** A 2D tile grid containing floor and wall tiles
- **WHEN** components is called with a target tile type
- **THEN** A list of distinct connected coordinate clusters is returned

### Requirement: ThinWalls

The system SHALL the extractor shall remove wall specks and decorative props below the minimum cell threshold by converting them to floor.

- **Implementation**: `thin_walls::tools/extract_sm_maps.py`

#### Scenario: RemoveSmallWallProps
- **GIVEN** A grid containing isolated wall clusters smaller than min_cells
- **WHEN** thin_walls is executed
- **THEN** Sub-threshold wall clusters are converted into floor tiles

### Requirement: CleanupGrid

The system SHALL the extractor shall execute multi-pass noise reduction to fill disconnected specks and plug pinholes.

#### Scenario: FilterPinholesAndSpecks
- **GIVEN** A grid with single-tile noise artifacts and pinholes
- **WHEN** cleanup is executed
- **THEN** Grid artifacts are smoothed across two passes

### Requirement: BridgeComponents

The system SHALL the extractor shall carve orthogonal l-shaped corridors connecting isolated floor islands to the main map landmass.

- **Implementation**: `bridge::tools/extract_sm_maps.py`

#### Scenario: ConnectDisconnectedFloorIslands
- **GIVEN** A grid containing multiple disconnected floor components
- **WHEN** bridge is called with component groupings
- **THEN** Connecting floor corridors are carved between islands and the primary floor mass

### Requirement: SealUnreachableFloors

The system SHALL the extractor shall convert any remaining unreachable floor islands into solid walls.

- **Implementation**: `seal::tools/extract_sm_maps.py`

#### Scenario: SealUnbridgedFloorIslands
- **GIVEN** A grid containing floor islands that could not be reached by bridging corridors
- **WHEN** seal is executed
- **THEN** Unreachable floor components are converted into walls

### Requirement: CropGrid

The system SHALL the extractor shall trim empty outer margins around the populated playable boundary of the grid.

#### Scenario: CropOuterMargins
- **GIVEN** A grid surrounded by unused outer border rows and columns
- **WHEN** crop is executed
- **THEN** The tight bounding box enclosing the active dungeon area is returned

### Requirement: CalculateTightShare

The system SHALL the extractor shall compute the proportion of floor tiles with two or fewer floor neighbours to assess corridor narrowness.

- **Implementation**: `tight_share::tools/extract_sm_maps.py`

#### Scenario: EvaluateCorridorTightness
- **GIVEN** A finalized dungeon tile grid
- **WHEN** tight_share is evaluated
- **THEN** The ratio of tightly constrained floor cells to total floor cells is returned

### Requirement: ExecuteExtractionPipeline

The system SHALL the extractor shall orchestrate the batch processing, conversion, cleaning, bridging, and serialization of dungeon wing maps.

#### Scenario: CompleteDungeonMapExtraction
- **GIVEN** Map image assets and CLI arguments specifying scale and execution flags
- **WHEN** main is called
- **THEN** Each wing map is processed and written to disk unless dry-run is specified
- **AND** Extraction statistics and quality metrics are logged


## Sub-components

> `ScarletMonasteryMapExtractor` is an orchestrator. Each sub-component below implements one logical block.

### Sub-component: LoadMapImage

> Implements: `load`

Loads and decodes image map data at the specified dimensions into raw pixel or tile values.

#### Requirement: LoadImageData

#### Scenario: ValidImagePath
- **GIVEN** A valid image path on disk and target dimensions (w, h)
- **WHEN** load is invoked with the path and dimensions
- **THEN** Decoded pixel data matching the target resolution MUST be returned.

### Sub-component: ClassifyPixel

> Implements: `classify`

#### Requirement: EvaluateColor

The system SHALL the block must map an rgb color triplet to a corresponding map tile character based on the specified mode.

#### Scenario: ClassifyFloorColor
- **GIVEN** RGB values corresponding to floor palette in the chosen mode
- **WHEN** classify is evaluated for the RGB triplet
- **THEN** The floor tile identifier character MUST be returned.

### Sub-component: ThinWalls

> Implements: `thin_walls`

Eliminates small decorative wall clusters below a minimum cell threshold to clear walkable space.

#### Requirement: FilterSpeckWalls

The system SHALL the block shall replace connected wall components containing fewer cells than min_cells with floor tiles.

#### Scenario: RemoveSmallProps
- **GIVEN** A grid containing isolated wall clusters smaller than min_cells
- **WHEN** thin_walls is executed
- **THEN** All wall components with size below min_cells MUST be transformed into floor tiles.

### Sub-component: CleanupGrid

> Implements: `cleanup`

Applies filtering passes across the grid to eliminate specks and close single-cell pinholes.

#### Requirement: NormalizeArtifacts

The system SHALL the block must execute two passes over the grid to fill noisy specks and plug open pinholes.

#### Scenario: PlugSingleCellPinhole
- **GIVEN** A grid containing isolated void pinholes within solid structures
- **WHEN** cleanup is run on the grid
- **THEN** Pinhole cells MUST be filled and small specks removed.

### Sub-component: SealUnreachableAreas

> Implements: `seal`

Converts all unreachable floor islands into solid walls so only reachable play area remains.

#### Requirement: ConvertOrphanFloors

The system SHALL the block shall detect disconnected floor islands and convert any island not connected to the main floor into wall tiles.

#### Scenario: SealDisconnectedIslands
- **GIVEN** A grid containing isolated floor sections disconnected from the primary floor mass
- **WHEN** seal is executed
- **THEN** All unreachable floor islands MUST be converted into wall tiles.

### Sub-component: BridgeComponents

> Implements: `bridge`

Carves connecting corridors between disconnected floor components and the primary connected mass.

#### Requirement: ConnectIslands

The system SHALL the block must connect disconnected floor components to the main mass by carving l-shaped floor corridors.

#### Scenario: CarveCorridorBetweenComponents
- **GIVEN** A grid and a list of distinct floor components
- **WHEN** bridge is called
- **THEN** L-shaped walkable corridors MUST connect each candidate island to the main mass.

### Sub-component: FindComponents

> Implements: `components`

Identifies and partitions contiguous connected regions of matching floor tiles within the grid.

#### Requirement: ExtractConnectedComponents

The system SHALL the block shall perform a flood fill across matching floor tiles and return all disjoint connected components.

#### Scenario: DetectSeparateFloorRooms
- **GIVEN** A grid with two separated floor regions
- **WHEN** components is called with floor='.'
- **THEN** The output MUST contain two separate coordinate sets corresponding to each room.

### Sub-component: CropGrid

> Implements: `crop`

Trims unnecessary exterior wall and empty borders to tightly bound the dungeon floor plan.

#### Requirement: ShrinkToContentBounds

The system SHALL the block must remove empty outer rows and columns surrounding active floor and interior wall elements.

#### Scenario: TrimPaddingBorders
- **GIVEN** A grid with 5 rows and columns of empty margin surrounding dungeon tiles
- **WHEN** crop is applied
- **THEN** The resulting grid dimensions MUST be reduced to the minimal bounding box enclosing non-margin
content.

- **GIVEN** A grid where majority of walkable tiles are 1-tile-wide corridors
- **WHEN** tight_share is calculated
- **THEN** A high fractional ratio value MUST be returned representing high corridor density.
