# Wowroguelike-story Specification

> Generated by openlore v1.2.0 on 2026-11-13 21:19

## Purpose

Encapsulates the branching narrative script, dialogue choices, boss encounter triggers, and quest
objectives for the Wailing Caverns dungeon story ('The Fang of the Nightmare').

## Requirements

> `src/WowRoguelike.Story/Scripts/wailing_caverns.ink.json`

### Requirement: StartEncounter

The system SHALL the story script shall trigger a boss combat encounter handoff to the simulation engine when the narrative reaches a dungeon boss chamber.

#### Scenario: LadyAnacondraEncounterTrigger
- **GIVEN** The party reaches the Fang Hall chamber
- **WHEN** Lady Anacondra rises from the silvered water
- **THEN** start_encounter is invoked with 'lady_anacondra'

#### Scenario: LordCobrahnEncounterTrigger
- **GIVEN** Lady Anacondra is defeated and the party reaches the bone dais chamber
- **WHEN** Lord Cobrahn confronts the party
- **THEN** start_encounter is invoked with 'lord_cobrahn'

#### Scenario: LordPythasEncounterTrigger
- **GIVEN** Lord Cobrahn is defeated and the party enters the third chamber
- **WHEN** Lord Pythas speaks from the ceiling
- **THEN** start_encounter is invoked with 'lord_pythas'

#### Scenario: LordSerpentisEncounterTrigger
- **GIVEN** Lord Pythas is defeated and the party advances to the blocked cavern tunnel
- **WHEN** Lord Serpentis blocks the tunnel ahead
- **THEN** start_encounter is invoked with 'lord_serpentis'

#### Scenario: MutanusTheDevourerEncounterTrigger
- **GIVEN** All four Fang leaders are defeated and the party enters the deep black waters
- **WHEN** Mutanus the Devourer rises from the depths
- **THEN** start_encounter is invoked with 'mutanus'

#### Scenario: DeviateHidesCompletion

- **WHEN** The post-Mutanus narrative beat executes

### Requirement: ContinueStory

The system SHALL the system shall step story execution forward, accumulating narrative text lines until reaching a dialogue choice point, an external encounter trigger, a quest completion trigger, or story termination.

#### Scenario: AdvanceNarrativeText
- **GIVEN** An active story with continuing narrative lines and no pending triggers
- **WHEN** Continue is called
- **THEN** Batched text lines are returned as Text events

#### Scenario: TriggerBossEncounter
- **GIVEN** The story reaches a boss encounter knot that calls start_encounter
- **WHEN** Continue is called
- **THEN** Story execution pauses and an Encounter event containing the boss identifier is returned

#### Scenario: TriggerQuestCompletion
- **GIVEN** The story reaches a quest completion point that calls complete_quest
- **WHEN** Continue is called
- **THEN** Story execution pauses and a QuestComplete event containing the quest identifier is returned

#### Scenario: HaltAtBranchingChoices
- **GIVEN** The story reaches a dialogue branch with available options
- **WHEN** Continue is called
- **THEN** Execution yields a Choice event containing indexed option tuples

#### Scenario: StoryReachesConclusion
- **GIVEN** The story reaches the ending knot with no further content
- **WHEN** Continue is called
- **THEN** An End event is returned signalling story completion

### Requirement: ChooseOption

The system SHALL the system shall select an active dialogue or branch choice by index to advance branching narrative flow.

#### Scenario: ValidChoiceSelected
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** The story has active choices and index is within valid range
- **WHEN** Choose is called with the choice index
- **THEN** The Ink runtime selects the corresponding branch and advances

#### Scenario: InvalidChoiceIndexProvided
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** The provided choice index is negative or out of bounds
- **WHEN** Choose is called
- **THEN** An ArgumentException is thrown indicating index is out of range

### Requirement: LoadJson

The system SHALL the system shall locate and load compiled story script json from embedded assembly manifest resources or candidate filesystem paths.

#### Scenario: LoadFromEmbeddedResource
- **GIVEN** An executing assembly containing an embedded resource matching the specified file name
- **WHEN** LoadJson is called with the file name
- **THEN** The JSON content is read from the manifest resource stream and returned

#### Scenario: FallbackToLocalDisk
- **GIVEN** No embedded resource matches but the script exists at a candidate file path on disk
- **WHEN** LoadJson is called with the file name
- **THEN** The JSON content is read from the disk path and returned

### Requirement: Continue

The system SHALL the storyrunner shall advance the story narrative until an encounter, quest completion, choice, or end event occurs, batching intermediate text lines.

#### Scenario: EncounterTriggered
- **GIVEN** A story where narrative text precedes a start_encounter external function call
- **WHEN** Continue is called
- **THEN** Batched Text events are emitted followed by an Encounter event containing the boss ID

#### Scenario: QuestCompletionTriggered
- **GIVEN** A story where narrative progression invokes complete_quest
- **WHEN** Continue is called
- **THEN** Batched Text events are emitted followed by a QuestComplete event containing the quest ID

#### Scenario: ChoicePromptReached
- **GIVEN** A story branch presenting multiple player options
- **WHEN** Continue is called
- **THEN** A Choice event containing indexed text options is returned

#### Scenario: EndOfStory
- **GIVEN** A story with no remaining content, pending functions, or choices
- **WHEN** Continue is called
- **THEN** An End event is returned

### Requirement: Choose

The system SHALL the storyrunner shall register a player's selected choice branch by index, throwing an argument exception if the index is out of bounds.

#### Scenario: ValidChoiceSelection
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** The story is currently waiting at a set of active choices and index is within valid bounds
- **WHEN** Choose is called with the index
- **THEN** The choice is applied to the underlying story interpreter

#### Scenario: OutOfRangeChoiceIndex
- **GIVEN** The story has active choices and an index outside the valid choice range is provided
- **WHEN** Choose is called
- **THEN** An ArgumentException is raised stating the choice index is out of range

### Requirement: LoadJson

The system SHALL the storyrunner shall resolve and load compiled ink json content from embedded assembly resources or candidate filesystem locations.

#### Scenario: LoadFromEmbeddedResource

- **WHEN** LoadJson is called with the file name
- **THEN** The resource stream is read and returned as a string

#### Scenario: FallbackToFilesystem
- **GIVEN** The specified JSON file is not embedded but exists in candidate directory paths on disk
- **WHEN** LoadJson is called with the file name
- **THEN** The file is read from disk and returned as a string

#### Scenario: ResourceAndFileNotFound
