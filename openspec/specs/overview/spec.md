## Purpose

A World of Warcraft-themed roguelike game and simulation engine implemented in F#. It simulates
dungeon encounters, procedural generation, combat mechanics, and turn-based simulation rules both
interactively and headlessly. The system provides performance benchmarking, golden replay
verification, and a playable desktop game experience.
