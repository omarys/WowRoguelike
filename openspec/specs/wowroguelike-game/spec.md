# Wowroguelike-game Specification

> Generated by openlore v1.2.0 on 2026-11-13 21:19

## Purpose

Encapsulates parsing and translation of raw textual commands and shell inputs into structured game
simulation requests and entity commands.

## Requirements

> `src/WowRoguelike.Game/Program.fs`

### Requirement: ParseCommand

The system SHALL the parser shall parse an input line against the current world state into a valid shell execution request or entity action command.

#### Scenario: ParsePauseCommand
- **GIVEN** An active world simulation and command text 'pause'
- **WHEN** parse is invoked
- **THEN** It MUST return Some Pause

#### Scenario: ParseValidAbilityUsage
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A world containing actor entity 1 with ability 'Lesser Heal' and target entity 2
- **WHEN** parse is invoked with '1 2 lesserheal'
- **THEN** It MUST return Some(Issue(UseAbility(1, 'Lesser Heal', 2)))

#### Scenario: ParseUnrecognizedCommand
- **GIVEN** An invalid or malformed command string
- **WHEN** parse is invoked
- **THEN** It MUST return None

### Requirement: NormalizeAbilityKey

The system SHALL the parser shall normalize an ability name by filtering out non-alphanumeric characters and converting to lowercase for punctuation-insensitive matching.

#### Scenario: StripPunctuationAndWhitespaceFromAbilityName
- **GIVEN** An ability name with punctuation and casing such as 'Druid\'s Slumber'
- **WHEN** key is invoked
- **THEN** It MUST return 'druidsslumber'

### Requirement: LookupGlyph

The system SHALL the font service shall return the 5-byte column bitmap for a character or return a solid block fallback glyph if unsupported.

#### Scenario: LookupSupportedASCIICharacter
- **GIVEN** A defined alphanumeric character 'A'
- **WHEN** ofChar is invoked
- **THEN** It MUST return the exact 5-byte array matching glyph 'A'

#### Scenario: FallbackForUnmappedCharacter
- **GIVEN** An unmapped character not present in glyphs map
- **WHEN** ofChar is invoked
- **THEN** It MUST return the default 5-byte solid block pattern

> `src/WowRoguelike.Game/Program.fs`

### Requirement: GetEntries

The system SHALL the menu service shall provide the list of all playable dungeon entries including difficulty bands, art paths, and start constructors.

#### Scenario: RetrieveAvailableDungeonList
- **GIVEN** A player requesting available dungeons at the menu
- **WHEN** entries is invoked
- **THEN** It MUST return dungeon entries for Screaming Gully, Wailing Caverns, and all Scarlet Monastery wings
with difficulty bands

### Requirement: StartScarletMonastery

The system SHALL the menu service shall construct a new world instance for a specific scarlet monastery wing scaled to the designated difficulty band.

#### Scenario: GenerateScarletMonasteryWorldAtMinimumDifficulty
- **GIVEN** A valid Scarlet Monastery wing name and band index 0
- **WHEN** scarletStart is invoked
- **THEN** It MUST initialize Content.scarletMonasteryAt with Minimum difficulty

### Requirement: LoadTextures

The system SHALL the game client shall discover all png sprite assets on disk and load them into premultiplied-alpha gpu textures keyed by relative path.

#### Scenario: LoadAndPremultiplySpriteTexturesFromDisk
- **GIVEN** An Assets directory containing PNG image files
- **WHEN** loadTextures is invoked
- **THEN** It MUST load each texture, apply premultiplied alpha color correction, and index them by relative
path without extension

### Requirement: BindCreatureArt

The system SHALL the game client shall assign sliced dungeon creature art slots to unique non-party creature names in stable alphabetical order.

#### Scenario: DeterministicallyAssignCreatureSpriteSlots
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A dungeon asset path prefix and a world populated with non-party hostile entities
- **WHEN** bindCreatureArt is invoked
- **THEN** It MUST map each distinct creature name to an available mob art slot deterministically

### Requirement: FollowCamera

The system SHALL the game client shall center the viewport camera on the selected entity or default party tank and clamp coordinates to grid boundaries.

#### Scenario: CenterCameraOnSelectedEntity
- **GIVEN** A currently selected entity positioned within the world grid
- **WHEN** followCamera is invoked
- **THEN** It MUST update camX and camY centered on the entity and clamped between 0 and grid bounds minus
viewport size

### Requirement: Run

The system SHALL the application shall initialize the monogame desktop host, load tileset assets, and run the primary game loop.

#### Scenario: SuccessfulGameLaunch
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** Application assets and runtime dependencies are available
- **WHEN** The game application entry point is executed
- **THEN** The desktop window is created and the game loop starts

### Requirement: LoadAssets

The system SHALL the application shall load sliced tileset png images from the assets directory into texture objects for runtime rendering.

#### Scenario: LoadTilesetTexturesFromDisk
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** PNG tile assets exist in the Assets directory
- **WHEN** Asset loading is triggered during game initialization
- **THEN** Texture2D instances are created from the asset files
